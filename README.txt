ПЕРЕГОННЫЙ ЦЕХ — PWA v3

Это веб-приложение, подготовленное для установки на iPhone как приложение.

ВАЖНО: открытие index.html напрямую из приложения «Файлы» НЕ является установкой PWA.
Файлы должны быть размещены на HTTPS-адресе.

На iPhone:
1. Откройте адрес приложения в Safari.
2. Нажмите «Поделиться».
3. Выберите «На экран Домой» / «Добавить на экран Домой».
4. Откройте приложение с новой иконки.

После установки приложение запускается в режиме standalone без обычной панели Safari.
Service Worker обеспечивает кэширование для последующей работы без сети.
